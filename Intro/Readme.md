# 🚀 Introduction to JavaScript (JS)

Welcome to the world of **JavaScript!** This README covers the fundamental concepts of JavaScript for beginners.

---

## 📌 1. What is JavaScript?

JavaScript (JS) is a popular programming language used to make websites interactive and dynamic.

It is a programming language in which we give instructions to a computer to perform specific tasks.

### ✨ Uses of JavaScript
- Making websites interactive.
- Handling button clicks and user actions.
- Creating animations and effects.
- Validating forms.
- Developing web applications.
- Building both frontend and backend applications.

## 🖨️ 2. Syntax of JavaScript (Printing)

Syntax refers to the rules and structure used to write a programming language.

In JavaScript, we use `console.log()` to display output in the console.

## 📦 3. Variables in JavaScript

A variable is a container used to store data in a program.

Variables help us store and manage information such as:

- Names
- Age
- Numbers
- Prices
- Other values

---

## 🔄 4. JavaScript is a Dynamically Typed Language

JavaScript is a **dynamically typed language**, which means we do not need to specify the data type while declaring a variable.

JavaScript automatically identifies the data type based on the assigned value.

### Key Points:
- No need to declare data types explicitly.
- A variable can hold different types of values over time.
- Data types are determined at runtime.

---

## 📏 5. Rules for Naming Variables in JavaScript

Some important rules for naming variables:

1. Variable names can contain letters, numbers, underscores (`_`), and dollar signs (`$`).
2. Variable names cannot start with a number.
3. Spaces are not allowed in variable names.
4. JavaScript keywords cannot be used as variable names.
5. Variable names are case-sensitive.
6. Always use meaningful variable names.

---

## 🏷️ 6. Types of Variables in JavaScript

JavaScript provides three main keywords for declaring variables:

### 🔹 1. var
- Can be redeclared.
- Can be updated.
- Has function scope.

### 🔹 2. let
- Cannot be redeclared in the same scope.
- Can be updated.
- Has block scope.

### 🔹 3. const
- Cannot be redeclared in the same scope.
- Cannot be reassigned.
- Must be initialized during declaration.
- Has block scope.

### 📊 Difference Between var, let and const

| Feature | var | let | const |
|:---|:---:|:---:|:---:|
| Redeclaration | ✅ | ❌ | ❌ |
| Reassignment | ✅ | ✅ | ❌ |
| Scope | Function | Block | Block |
| Initialization Required | ❌ | ❌ | ✅ |

💡 **Best Practice:** Use `const` by default and `let` when you need to reassign a variable. Avoid using `var` in modern JavaScript.

## 🧩 7. Data Types in JavaScript

A data type defines the kind of value a variable can store.

JavaScript data types are divided into two main categories:

### A. Primitive Data Types

JavaScript has 7 primitive data types:

| Data Type | Description |
|:---|:---|
| Number | Stores numeric values. |
| String | Stores text and characters. |
| Boolean | Stores true or false values. |
| Undefined | Represents a variable without an assigned value. |
| Null | Represents an intentional absence of a value. |
| BigInt | Stores very large integers. |
| Symbol | Represents unique identifiers. |

### B. Non-Primitive Data Types

These are also known as reference types.

| Data Type | Description |
|:---|:---|
| Object | Stores data in key-value pairs. |
| Array | Stores multiple values in a single collection. |
| Function | A reusable block of code designed to perform a task. |
